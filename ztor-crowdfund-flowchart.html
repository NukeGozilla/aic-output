Notes & deferred items

  • Out of scope (Stage 3): creator self-serve portal, automated refunds, automated revenue reports, Stripe Payouts to creators, link-attribution eligibility, pre-launch state, push notifications.
  • Pledges live on the user profile at /profile/[username]?tab=pledges, not on a standalone page. Legacy /crowdfund/my-pledges 307-redirects.
  • Creator profile at /profile/[creator]?tab=campaigns shows aggregate KPIs + per-campaign progress + recent backers. Read-only in Stage 2 (no announcement publishing from creator profile yet).
  • Wording rule: 募資 = program · 贊助 = user verb · 投資 banned in user-facing copy.
  • Currency: user-local (HKD for HK, TWD for TW). All tier prices are stored as numbers in the project's currency.
  • Open items still gating dev: O3 final eligibility list (Agnes legal), O4 final notification list (Ops). See open-questions page for the full list.
