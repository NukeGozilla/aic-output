Beamco Full vs. Ztor Simple — Key Differences

Aspect Beamco (Full System) Ztor (Simple / MVP)
Funding tiers Dynamic plans with items, price, share count SYSTEM Hardcoded fixed amounts (e.g. $100, $500, $5K) HARDCODE
Payment model Reserve now, charge on success (Stripe Future Payment) SYSTEM Immediate charge at time of backing SYSTEM
Artist Portal Full self-serve portal for artists to create & manage projects SYSTEM No portal — all setup handled offline by Ztor team MANUAL
Creator negotiation Artist contract with dynamic terms, in-platform agreement SYSTEM Offline negotiation, terms set manually MANUAL
Loyalty / Eligibility Follow X days → earn Y points → unlock eligibility SYSTEM None — anyone can back a project

Updates / Comments Full update system with 3 types, attachments, visibility controls SYSTEM Basic announcements — tech evaluation needed for comments
Refund on failure No charges collected (reserve model) SYSTEM Manual refund of collected payments MANUAL

Key Decisions & Notes from Meeting (Apr 13, 2026)

  • Validate first, build later — the entire approach is "ship a manual MVP to test if the crowdfund business model works on Ztor before investing in a full system."
  • Don't port Bingo (Beamco) system — the most complex part is Artist Portal, which isn't needed. Front-end is relatively simple.
  • Parallel workstreams — Bingo system migration (Kerry & Eric) runs alongside this lightweight Store crowdfund (Indonesia AI team, onboarded as of Apr 13).
  • Standalone page — crowdfund project lives on its own page, doesn't change main Store site architecture. After funding completes, page converts to a regular video page.
  • First crowdfund project could happen by end of May 2026 — likely an AI contest creator wanting to produce a longer series or pay-per-view short series.
  • Revenue share is simple math — Store already tracks earnings per film. Backer % is known from the funding. Manual calculation & payout.
  • Comments / activity announcements need tech evaluation — may be separate from main site comment system. Deferred if complex.
  • Creator onboarding is fully offline — Ztor team contacts creator, negotiates terms, sets everything up. No self-service.
