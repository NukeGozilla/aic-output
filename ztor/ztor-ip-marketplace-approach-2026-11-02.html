1 · The question for this meeting

How do we take the IP Marketplace to the AI-creator community?

L's framing (Nov 1): push it out as a content-creation tool on its own, or as part of a whole suite of features.

Option A

A tool: "Rent licensed IP for your AI videos"

IP Marketplace alone. Creators rent, make the video anywhere, publish anywhere.

  • Narrow, fast, one sentence to explain
  • Works with a small inventory
  • Lands before the rest of 2.0 is live
Risk: we look like a stock-asset site; no reason to stay on Ztor.
Option B

A suite: IP + contests + publishing + revenue rails

Rent IP → create → enter AIC → publish on Ztor → earn through the waterfall.

  • Bigger story, the "Follow the Money" pitch
  • Lock-in: the content lives and earns on Ztor
  • Needs Creator Studio, AIC and payouts live first
Risk: slow; a lot must be true before the first creator sees value.
Proposed stance to react to (Jeff's draft, not agreed)
A is the door, B is the room. Market the tool to the AI-creator community; the suite is what they find after signing up. First listings are contest packs, so the content team gets value on day one.

3 · Three layers, built in this order

Registry first (internal), marketplace second (Ztor site), owner upload last

Layer 1 · now

IP Registry

Internal · ops + dev
  • IP types: likeness · character · footage/stills · script · music · contest pack
  • Owner (linked user or temp account), consent on file
  • Asset pack, permitted uses, licence options, visibility
Mostly exists: IP Bank back office (add entry, owner link, 3 payout models, earnings report). Add the marketplace fields.
Layer 2 · next

Marketplace

Ztor site · creators are Ztor users
  • Browse → IP detail with licence sheet → request / rent
  • Download the pack, track licences in "My licences"
  • Contest packs listed first; open rentals on the same surface
To confirm: Jul 23 ruling placed IP Bank inside Creator Studio, not the fan site.
Layer 3 · later

Add-IP UI

IP owners · self-serve
  • Owner uploads IP, sets terms and price
  • Ops approves before listing (consent gate stays)
  • Public iStock-style browse once inventory justifies it
Gated on inventory count, no date.
Rental flow: Owner registers → Creator finds & requests → Owner / ops approves → Pack delivered, licence logged → Creator publishes → Owner paid via IP Bank payout model
