ZTOR · LLOUD + Creator API

The fast lane: how LLOUD features get built, and how they reach Ztor

A LLOUD feature is specced in one page, designed, built on the Creator API and shipped on lloud.club first. The business team then sees it working and decides how it folds into ztor.com.

Draft for discussion 4 Nov 2026 Owner: Jeff For: L · Eric · Dolly · Nan · biz team
01 · In one line

LLOUD is Ztor's fast lane. Product → design → build → live on LLOUD → shown to the business team → they decide: fold into Ztor, keep it LLOUD-only, or drop it.

05 · The boundary

What the lane may touch, and what needs a call first

In the lane, no gate

  • New Creator API endpoints and fields, scoped to the channel
  • New per-channel settings (precedent: points board shared or separate)
  • LLOUD site features and LLOUD console screens
  • Loyalty, missions and vault rules for LLOUD's own board

Jeff's call before Build

  • Anything a fan on ztor.com would see or feel
  • Money rules: payment methods, currency, fees, payout, void
  • Shared data: identity, order schema, the shared loyalty board, ztor.com's tier bands
  • Bookyay / ticketing integration
  • Ztor's locked Phase 0 loyalty rules (LLOUD gets its own model; Ztor keeps Phase 0)

Whether a capability is switched off for ztor.com is decided per spec, not by a standing rule. New work is designed so the two sites can separate later (dev sync, 19 Oct).

06 · Fold-in

How a LLOUD feature reaches ztor.com

The brief (one page, for the biz team)
  • What it is: 30-second demo on lloud.club
  • What LLOUD learned: usage, L's feedback, what changed
  • What Ztor would need: Creator Studio screens, ztor.com FE, any policy question
  • Options: adopt as is · adapt · LLOUD-only · drop, with Jeff's recommendation
  • Cost: Eric's sizing of the Ztor half (the API half is done)
Fold into ZtorTask multi-homed onto the Feature Board and the Roadmap release; BRD only if a business policy is involved. Ztor-stream work from here.
LLOUD-onlyStays a channel feature. Revisit when a second artist site wants it.
DropRemoved from LLOUD or left dormant.
07 · Example

Membership card

Why this one
Out of Ztor's loyalty MVP (30 Oct). Parked as "LLOUD Phase 1+" (3 Nov). L wants it.
Spec + design
Card in the fan pass: tier, member number, join date, QR for offline check-in. Card art set in the console. One screen.
Build + ship
One read endpoint from existing loyalty + account data, one channel setting. December drop on lloud.club.
Show + fold
Brief at the next alignment. Likely questions: paid membership? one card per artist on ztor.com? If adopted: Creator Studio card settings under the 2.4 loyalty admin.
