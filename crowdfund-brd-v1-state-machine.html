State definitions

WHAT EACH STATE MEANS AND HOW THE CAMPAIGN BEHAVES WHILE IT'S IN THAT STATE

Draft

Campaign being configured. All fields editable. Not visible to fans. Can be deleted.

Pre-publish · Internal only

Active

Campaign published and live. Fields locked. Fans browse + pledge (card collected, no charge). Edit lock per BR-23.

Live · pledges open

Goal Achieved

raised ≥ minGoalUsd at any point during Active — may fire pre-end-date (per BR-N3). Pledging stays open through end-date · no hard cap on raised. Batch-charge (BR-28) fires only on end-date. Recovery loop runs on declines (BR-29 / BR-30 / BR-31 / BR-N4) · pure FIFO refill with no overshoot skip. Renamed from "Funded" (2026-05-25) · trigger updated 2026-05-27 for range-threshold model.

Transitional · charging

Unsuccessful

End date reached, goal NOT met. Zero charges fired. No refunds needed (nothing was taken). Terminal.

Terminal · stop

Successful

Recovery loop complete; ops has manually reviewed the failure rate via the BR-32 dashboard and approved payout. First tranche (80% minus 4% payment + 5% crowdfund platform fee) released to creator wallet.

Money moved · first tranche

In Progress

Creator producing work. Status updates allowed. Awaiting final product URL submission to trigger Released.

Production window

Released

Spotify URL submitted by ops (BR-35 walkthrough update). Second payout tranche (20%) released. Royalty reporting / cash flow deferred to post-MVP (BR-36).

Terminal · royalty active

Cancelled

Reached from Active, Goal Achieved, or In Progress. All backers refunded (via Stripe back-office, manual). Listing retained with Cancelled status. Terminal.

Terminal · refund-all

Fan Order State Machine

PER-FAN, PER-PLEDGE — DISTINCT FROM THE CAMPAIGN STATE MACHINE ABOVE

Each fan's pledge runs through its own lifecycle — independent of the campaign state. Two fans on the same campaign can be in different order states at any time (one Charged, one Failed retry, one Refunded). The UI shows both pills together — order state (what's happening with your money) and campaign state (what's happening with the project).
