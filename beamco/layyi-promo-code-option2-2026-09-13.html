Dev delta

Data model — promo_code

  • discount_type enum percent | fixed (today: percent only)
  • discount_value decimal (today: rate %)
  • applies_to enum all | items, default all
  • promo_code_items (promo_id, target_type event | item | bundle, target_id) — empty when all

Admin rule — enforce at config time

  • A bundle is its own product: selecting a single item never covers a bundle containing it, and selecting a bundle never covers its parts sold separately

Checkout rule — enforce server-side at order creation

  • Code active in window, case-insensitive, one code per order, single-use per customer (existing)
  • Eligible lines = all lines if all, else lines whose item ∈ promo_code_items
  • No eligible line → reject: "Promo code is not valid for items in your cart."
  • Discount applies to every eligible unit in the order — percent → Σ eligible line totals × rate · fixed (unused for LAYYI) → min(value, Σ eligible line totals). Client-confirmed 16 Sep, Listings note 1
  • Order stores an eligible flag per line so reporting shows which lines were discounted
  • Per-order quantity limit per ticket type (max 4) — the product form already carries Purchase limit (S35 · 每人限購); dev to confirm it enforces per order, not only per customer

Platform fee — separate ticket, platform-wide

  • platform_fee = (subtotal − discount) × rate — changes the basis for every shop, not just LAYYI → needs effective date, forward-only
  • Order stores: original subtotal · code · discount amount · post-discount subtotal · fee

Agreed with dev

  • Rules live in the artist portal, not hard-coded — easier to test and adjust
  • Discount type: percentage (fixed amount built but unused for LAYYI)
  • Multi-select applicable products — dev confirms no significant added complexity
  • Targets are events, single items and bundle packages; a bundle is a distinct product
  • One code per order, no stacking
  • Promo entry stays at checkout, not the cart — unchanged

Confirmed by client 16 Sep — Listings tab

  • Discount applies to the entire eligible quantity, not a single item — 3 General Entry with the 100% code = all 3 free. Replaces Monday's highest-priced-item rule
  • Three percentage codes: 100% on General Entry + Door · 10% and 20% on General Entry + Door + Vinyl + Stickers. Early Bird, Priority Entry and every bundle excluded
  • No fixed-amount and no store-wide discounts needed
  • Per-order limit of 4 per ticket type; each code single-use per customer
