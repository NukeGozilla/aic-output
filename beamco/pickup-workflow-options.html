Pickup Scheduling — Fulfillment Flow Options

Beamco PRD Feedback Discussion · March 2026

Shared Starting Flow (all options)
Every option begins with the same trigger: fan places an order, system notifies both Creator and Admin.
flowchart LR
    A["🛒 Fan places order"] --> B["📩 System sends\nNew Order notification"]
    B --> C["👤 Creator notified"]
    B --> D["👔 Admin notified"]
A Current Workflow — Admin sends label to Creator

✅ This is how the system works today. Admin is the full coordinator. Creator receives the label passively via communication channel or email.

flowchart TD
    A1["👔 Admin creates shipping label\n(via courier system)"] --> A2["Admin sends label\nto Creator\n(comm channel / email)"]
    A3["👤 Creator prepares order"] --> A4["Creator packages order\n+ attaches label"]
    A2 --> A4
    A4 --> A5["👔 Admin schedules pickup\nvia Back Office"]
    A5 --> A6["📩 Pickup Scheduled\nnotification → Creator"]
    A5 --> A7["📩 Tracking link\nvisible to Fan"]
    A7 --> A8["🚚 Courier picks up"]
    A8 --> A9["Fan receives order ✅"]
Who does what
Admin: label + schedule + send Creator: prep + package
Pros
  • Simplest for creators — they just receive and attach
  • Admin has full visibility and control
  • No Artist Portal development needed
Cons
  • High admin workload — manual send per order
  • Bottleneck as order volume grows
  • Depends on comm channel reliability
B Admin creates label + Creator downloads from Portal

Admin still creates the label, but it's uploaded to the Artist Portal. Creator self-serves the download.

flowchart TD
    B1["👔 Admin creates shipping label\n(via courier system)"] --> B2["Label uploaded to\nArtist Portal"]
    B3["👤 Creator prepares order"] --> B4["Creator downloads label\nfrom Artist Portal"]
    B2 --> B4
    B4 --> B5["Creator packages order\n+ attaches label"]
    B5 --> B6["👔 Admin schedules pickup\nvia Back Office"]
    B6 --> B7["📩 Pickup Scheduled\nnotification → Creator"]
    B6 --> B8["📩 Tracking link\nvisible to Fan"]
    B8 --> B9["🚚 Courier picks up"]
    B9 --> B10["Fan receives order ✅"]
Who does what
Admin: label + schedule Creator: download + prep + package System: hosts label in Portal
Pros
  • Removes manual send step — less admin friction
  • Creator can download label anytime
  • Audit trail in Portal (who downloaded when)
Cons
  • Requires Artist Portal dev (label upload + download UI)
  • Admin still creates the label manually
  • Creator needs to know to check Portal
C Full Automation — Creator self-manages via Portal

Creator handles label creation, pickup scheduling, and packaging entirely from the Artist Portal. Admin only steps in if something goes wrong.

flowchart TD
    C1["👤 Creator creates\nshipping label\n(from Artist Portal)"] --> C2["Creator schedules pickup\n(from Artist Portal)"]
    C2 --> C3["Creator packages order\n+ attaches label"]
    C3 --> C4["📩 Tracking link\nvisible to Fan"]
    C4 --> C5["🚚 Courier picks up"]
    C5 --> C6["Fan receives order ✅"]
    C7["👔 Admin monitors dashboard"] -.->|"Only if issue"| C8["Admin assists Creator"]
Who does what
Creator: label + schedule + package Admin: support only
Pros
  • Scales best — admin is not a bottleneck
  • Creator has full control and faster turnaround
  • Reduces ops headcount needed
Cons
  • Largest dev effort (full Portal: labels + scheduling)
  • Risk of missed pickups if creators are disengaged
  • Some creators may struggle with self-service
Side-by-Side Comparison
Dimension Option A — Current Workflow Option B — Portal Download Option C — Full Automation
Label creation Admin Admin Creator
Label delivery Admin sends via comm channel Creator downloads from Portal Creator generates in Portal
Pickup scheduling Admin (Back Office) Admin (Back Office) Creator (Artist Portal)
Admin involvement High — every order Medium — creates label, schedules Low — support only
Portal dev required None Label download UI Full: labels + scheduling + dashboard

Best for Closed beta / small volume Growing volume, transition phase Scale / post-beta
Shared Ending Flow (all options)
After pickup is scheduled, the remaining steps are the same regardless of option.
flowchart TD
    K["📩 Pickup Scheduled\nnotification → Creator"] --> L["📩 Order status updated\n(tracking link → Fan)"]
    L --> M["🚚 Courier picks up package"]
    M --> N{"Pickup successful?"}
    N -->|"Yes"| O["Order → In Transit\nFan tracks via link"]
    N -->|"No / Missed"| P["⚠️ Late-shipment alert"]
    O --> Q["Fan receives order ✅"]
    P --> R["Nudge to Creator + Admin"]
