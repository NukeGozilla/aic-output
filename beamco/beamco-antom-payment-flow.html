Summary

Checkout page redesign: Payment method list now shows on Beamco's page with wallet logos. Each method is tagged as ANTOM or STRIPE behind the scenes (users don't see this). Methods auto-filter by currency.

Antom flow (wallets): 3 screens only. Beamco → Wallet App → Beamco. No Antom hosted page. Antom pay API returns a direct redirect URL to the wallet.

Stripe flow (cards): Unchanged from today. Beamco → Stripe checkout → Beamco.

Crowdfunding: Stays entirely on Stripe (future/scheduled payments).

Why mixed: Antom requires separate compliance for CC/Apple/Google Pay. Stripe is already compliant. Don't block the local wallet rollout.
