Scope notes for dev

In scope here: the back-office Commission selector only (the two states above).  Out of scope: the front-end profile display of the % — that lives on the user profile page and the visual is owned by the designer; backend just exposes it via API (BR-11).

Two models, one flag: a single commission_mode per TM drives both logic sets — there is no "invited/non-invited" concept in the system. P0 / PH-01 commission_mode = manual → admin selects from 10/12/15 (State A). P1 / PH-02 commission_mode = auto → monthly auto-calc from gross revenue (State B), gated on revenue-data feed + marketing-confirmed tiers.

A TM record carries: commission_rate · commission_mode = manual | auto (defaults to manual) · updated_at. The commission_mode flag decides whether State A or State B renders.
