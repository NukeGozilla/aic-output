Crowdfund Lifecycle BRD v1

End-to-end journey of a campaign: Setup → Active → Funded → Successful → Released
← Main BRD Lifecycle State machine Payment retry & cancellation
●
All-or-nothing, two-tranche payout. Card is collected at pledge but NOT charged. On end date, if goal met → batch-charge → recovery loop → 80% payout. On product URL submission → final 20% payout. Royalty income flows after Released.

A unified lifecycle for both Music (Beamco) and Movies (Ztor) campaigns. The shape is the same; product-specific differences (currency, share denomination, royalty source) only matter at the data layer. Lifecycle = 4 phases: Setup → Live → Collection → Payout & Release.

Worst-case timeline · backer POV

Day 0 → 30
Campaign live. Backer pledges, card recorded, no charge. Maximum 30-day fundraising window.
Day 30
Campaign closes. If goal met → batch-charge. Otherwise → Unsuccessful, nothing happens.
Day 30 → 40
Recovery on declines. 3-day silent retry + 7-day email URL. If still failing on day 10 → drop + pull waitlister + restart cycle.
Day 40 → 50
Waitlister recovery (worst case). Another 3+7 cycle if the original substitute also declines.
Day 50
Threshold check. If failure% > threshold → cancel + refund all. Else → status = Successful + first tranche (80%) released.
Day 50 → 60
"Up to 30 days" buffer. Communicate this to creators — actual worst case is 20 days; 10-day safety buffer.
Weeks → months
Creator delivers → uploads Spotify (Music) or Ztor OTT (Movies) URL → status = Released → 20% tranche releases.
Ongoing
Royalty cash flows. Shares-to-cash bridge converts share holdings into withdrawable cash in fan + creator wallets (≥ USD 50 to withdraw).

Music vs Movies — where the lifecycle differs

SAME LIFECYCLE SHAPE · DIFFERENCES ARE DATA POINTS + ROYALTY SOURCE

♪ Music (Beamco)

Setup uses royalty shares % + count. Publish = Now only. Engagement = creator-only Updates feed. Product URL = Spotify link. Royalty = Flow A (Beamco-as-label, manual weekly) OR Flow B (contributor on distributor) — TBD.

▶ Movies (Ztor)

Setup uses revenue shares % + count. Publish = Now + Schedule. Engagement = open Comments (with admin soft-delete). Product URL = Ztor OTT link. Royalty = instant from Ztor OTT pipeline. Creator wallet adds tastemaker referral fee row.
