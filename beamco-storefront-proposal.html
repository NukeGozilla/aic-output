UX Proposal: "My Inventory" vs "My Shop"

Eliminate creator confusion by merging product lists into one view, and giving the storefront its own dedicated job.

🔴 The Current Problem

Today, creators see "My Inventory" and "My Shop" side by side in their portal. Both display the same list of products in the same format. The only intended difference — Inventory shows all items, Shop shows only listed items — is invisible when everything is listed.

This creates a "which one do I click?" moment every time a creator wants to manage their products. The result: confusion, second-guessing, and wasted time.

Root cause

Two separate sections are trying to answer the same question: "What products do I have?" The distinction (all vs. listed) is better served by a filter within one view, not by duplicating the entire interface. Meanwhile, storefront configuration (branding, layout, public URL) has no dedicated home.

Key shift

The old "My Shop" was a product list — which is now handled by "My Products." This new "My Storefront" answers a completely different question: "What does my shop look like to fans, and how do I customize it?" It gives creators a live preview plus configuration controls, similar to Shopify's "Online Store" section. Only listed products appear in the preview — reinforcing the status system from My Products.

Before → After

❌ Before

Two sections, one job, maximum confusion

  • 📋 "My Inventory" shows all products in a list
  • 📋 "My Shop" shows listed products in the same list format
  • 😕 Both look identical when everything is listed
  • 🚫 No draft status visibility
  • 🚫 No storefront branding or configuration anywhere
  • 🚫 No product type differentiation (events vs merch vs digital)

✅ After

Two sections, two distinct jobs, zero confusion

  • 📦 "My Products" — single source of truth for all products with status filters (All / Listed / Unlisted / Draft)
  • 🏪 "My Storefront" — dedicated shop configuration: branding, layout, public URL, and live fan-view preview
  • 🏷️ Product type tags make it easy to scan across events, merch, digital, and crowdfunding
  • 👁️ Only listed products appear in storefront preview — reinforces the status system
  • 🎯 Follows the Shopify mental model creators already know

Implementation note

This is a restructure of two existing views into two redefined views — the data model doesn't need to change significantly. Products keep their listed/unlisted/draft status. The main engineering work is building the storefront configuration panel and preview, and merging the two product lists into one filtered table. Navigation labels change from "My Inventory / My Shop" to "My Products / My Storefront."
