Key system interactions

EventFromToWhat happens
Pledge submitted /crowdfund/[slug]/pledge Stripe + Pledges DB + Notification Stripe Future Payment intent created · pledge row inserted with state = pending · N1 fired
Funding period end (Funded) State Machine cron Stripe + Pledges DB + Notification Project state → Funded · batch capture all pending pledges · N5/N6 per result
Funding period end (Unsuccessful) State Machine cron Pledges DB + Notification Project state → Unsuccessful · zero charges · N7 fired to all backers
Card decline at capture Stripe webhook Capture service + Notification Pledge state → card_update_required · grace deadline set · N2 + N3 (day 3) reminders fire
Refund processed (rare edge) Ops in Stripe console Stripe webhook → Pledges DB + Notification Webhook updates pledge state → refunded · N8 fired · Ops audit row in /admin/pledges
State transition (manual) Ops in /admin dashboard State Machine + activity log + Notification Validates allowed next state · writes activity log · fires notification per transition (e.g., N11 on Released)
