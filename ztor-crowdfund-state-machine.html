v5.4 update (2026-05-22) — Ops team naming convention applied. 募資中, 募資失敗, and 募資成功 are DO NOT USE wordings going forward.

Renamed states:
· 募資中 → 計畫進行中 (Live) — funding period is open
· 募資失敗 → 計畫失敗 (Unsuccessful) — goal not met, no charge
· 募資成功 → 即將投入製作 (Awaiting Production) — funds collected, awaiting disbursement

New states:
· 即將開放 (Coming Soon) — pre-launch, page is set up but funding hasn't started
· 開放後補名單 (Wait List) — opt-in waitlist when goal is hit before period ends. Not for this stage — reserved for the next iteration of the simple version.

Other changes:
· "Edge case · creator default before production starts" now sits on 目標達成 → 已取消 (per ops sheet).
· Retained per ops request (not on current ops sheet, kept as fallback): Live → Canceled (ops pulls mid-flight) and Awaiting Production → Canceled (manual cancel).
· Live → Goal Achieved trigger refined: "Pledged total ≥ goal on or before funding period end · batch capture fires, no waiting list is available."
v5.3 background (2026-05-19) — Funding outcome was split into two states per Asana 1214919…5433 (section 1.17 Crowdfunding - Simple version (May 31st)): 目標達成 (Goal Achieved) = system detects pledged total ≥ goal; 即將投入製作 (Awaiting Production) = ops confirms every payment cleared post-retry. v5.4 keeps that two-state split and only renames per ops conventions.
